Politique de Confidentialité

Dernière mise à jour : 11 février 2026

1. Introduction

Livemory ("nous", "notre" ou "l'application") respecte votre vie privée. Cette politique explique comment nous collectons, utilisons et protégeons vos données personnelles.

2. Données Collectées

Nous collectons les données suivantes :

  • Numéro de téléphone : Utilisé pour l'authentification via Firebase Authentication
  • Photos et vidéos : Partagées volontairement par vous pour créer des souvenirs d'événements
  • Contacts : Accès optionnel pour inviter vos amis à des événements
  • Informations de profil : Nom, photo de profil (optionnelle)
  • Localisation : Optionnelle, utilisée uniquement pour les détails d'événements

3. Utilisation des Données

Vos données sont utilisées pour :

  • Vous authentifier et sécuriser votre compte
  • Vous permettre de créer et participer à des événements
  • Partager des photos et vidéos avec les participants d'événements
  • Améliorer l'expérience utilisateur de l'application

4. Partage des Données

  • Aucune vente : Nous ne vendons jamais vos données à des tiers
  • Firebase/Google Cloud : Vos données sont stockées de manière sécurisée sur l'infrastructure Firebase (Google Cloud Platform)
  • Participants aux événements : Les photos et informations que vous partagez dans un événement sont visibles par les autres participants

5. Sécurité

Nous utilisons Firebase Authentication et Firestore avec des règles de sécurité strictes pour protéger vos données. Toutes les communications sont chiffrées (HTTPS).

6. Vos Droits

Vous avez le droit de :

  • Accéder à vos données personnelles
  • Modifier ou supprimer vos informations
  • Supprimer votre compte à tout moment depuis les paramètres de l'application
  • Retirer votre consentement pour l'accès aux contacts ou à la localisation

7. Suppression des Données

Pour supprimer votre compte et toutes vos données :

  • Ouvrez l'application → Paramètres → Supprimer mon compte
  • Ou contactez-nous à : support@livemory.app

La suppression sera effective sous 30 jours maximum.

8. Permissions de l'Application

  • CAMERA : Pour prendre des photos à partager dans les événements
  • READ_MEDIA_IMAGES / READ_EXTERNAL_STORAGE : Pour sélectionner des photos depuis votre galerie
  • INTERNET : Pour la synchronisation avec Firebase
  • READ_CONTACTS : Optionnel, pour inviter vos amis

9. Services Tiers

L'application utilise les services suivants :

  • Firebase (Google) : Authentification, base de données, stockage
  • Politique de confidentialité de Google : https://policies.google.com/privacy

10. Modifications de cette Politique

Nous pouvons modifier cette politique de confidentialité. Les changements seront publiés ici avec une nouvelle date de mise à jour.

11. Contact

Pour toute question concernant cette politique de confidentialité ou vos données personnelles, contactez-nous :

  • Email : support@livemory.app
  • Application : Livemory
